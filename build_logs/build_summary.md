## 3. PBIX location

The `.pbix` binary is produced by Power BI Desktop on the user's machine — the binary VertiPaq columnar format cannot be encoded outside the proprietary engine. After opening either PBIP in Power BI Desktop, the user clicks *File → Save As → DecodingCustomerValue.pbix* (~30 seconds).

## 6. Remaining issues

1. **The user needs to enable PBIR preview features in PBI Desktop** (one-time, ~30 seconds) for the full Path A dashboard to render all 40 visuals. Without this, the semantic model loads but the report tier is silently dropped — a known limitation of the Microsoft Store edition flagged in Microsoft's own docs. The model-only Path B is the fallback that needs no toggle.
2. **Bookmark filter states are empty** — the bookmark scaffolding is correct, but capturing the actual filter state requires one right-click-and-Update per bookmark in PBI Desktop. Documented in QA report §"Remaining issues".
3. **Cross-visual interaction overrides** (spec Step 8) — PBIR doesn't expose the per-pair interaction matrix in a CLI-safe way. The default cross-filter behaviour is on; if the user wants custom overrides (e.g. Panel 2 *highlights* Panel 1 instead of filtering), it's 4 clicks in *Format → Edit interactions*.
4. **PBIX file production** — cannot be done outside Power BI Desktop; user clicks *File → Save As* once the PBIP is open.
