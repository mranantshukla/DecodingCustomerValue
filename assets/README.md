# Assets

Drop presentation media here. These paths are already referenced by the root
`README.md` and the Power BI guide:

| File | What | How to capture |
|---|---|---|
| `founder_dashboard_mockup.png` | Matplotlib 2×2 mockup of the four-panel Founder Dashboard | Auto-generated by `python scripts/render_founder_dashboard_mockup.py` |
| `DecodingCustomerValue.pbix` | The real Power BI dashboard binary | Open `powerbi/dashboard/DecodingCustomerValue.pbip` in Power BI Desktop → *File → Save As* → save here |
| `powerbi_founder.png` | Screenshot of the Founder page (Page 1) | Open the `.pbix`, screenshot the page |
| `powerbi_companion_demographic.png` | Screenshot of Companion C (Demographic Opportunity) — optional | screenshot |
| `demo.gif` | 20–30s Streamlit walkthrough (cockpit → simulator) | Screen-record `streamlit run src/dashboard/app.py`; export GIF |

Keep images < 2 MB (the pre-commit `check-added-large-files` hook enforces this).
